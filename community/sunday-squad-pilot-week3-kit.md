## What week 3 is (and is not)

Week 3 pays off the ritual, it does not relaunch it. Same slot, same shape as
weeks 1–2, plus a two-week bridge and a finale lookahead. The only net-new
item in this kit is the voice-unavailable fallback (§3). Run-of-show (§2) and
retro (§4) mirror the established Squad beat layout with late-pilot deltas
only — the canonical layout lives in the week-4 agenda file, not here.

Why this copy: "two Sundays in and the ritual's holding" marks continuity
without re-explaining the event — regulars feel ownership, newcomers get the
same three friction removers (free, no sign-up, come-as-you-are). The finale
line points at the already-drafted week-4 agenda; it promises the slot, not a
format change. No @everyone — audience is whoever is already around; mention
policy stays with CPO.

## 3. Fallback plan if voice is unavailable (net-new in this kit)

Trigger: at T-30 min the host joins Lobby voice from the event device. If the
host cannot connect or cannot be heard, they get a 10-minute retry box
(rejoin, restart client, try mobile). Still dead after the box → the host
declares the fallback in the Lobby text chat and runs one of the below. The
host never no-shows silently and never improvises a second event.

| Path | Owner | Timebox | When |
|---|---|---|---|
| A. Text-channel party | Host | 20:00–20:15 assembly, then the hour | Voice down but text + game work: host posts the assembly note (see below), builds the Fall Guys party via in-game friend adds, narrates between rounds in text |
| B. In-room play | Host | Remainder of the hour | Voice *and* party-assembly both dead: play something in the room itself (a built-in activity / watch-together), zero install, zero voice. Host names the option in the T-30 fallback post — decided in advance, not mid-crisis |
| C. Cancel truthfully | Host posts; CM logs | Post by 20:15 | Neither A nor B is possible: post the cancellation note naming the voice outage as the cause. No substitute drafted same-day; the retro (§4) is still filled; the week-4 finale is unaffected |

Assembly-note text (path A, paste-ready):

```text
🎮 **Sunday Squad — voice is down, party is not**

Lobby voice isn't cooperating tonight, so we're assembling here. Drop your Fall Guys name (Epic ID) in this channel and I'll get you into the party — same hour, same zero sign-up, just typed between rounds instead of talked.

First show queues at 8:10 sharp. 👑
```

Cancellation-note text (path C, paste-ready):

```text
🎮 **Sunday Squad week 3 — cancelled (voice outage)**

Lobby voice is down and we can't run the party tonight. Truthful log: [N] heads at doors, voice dead since [TIME]. The pilot record stands at two completed weeks; the week-4 regular run is unaffected. See you next Sunday. 👑
```

Rules: no DMs to round people up (the bot never DMs; neither does the host),
no second RSVP path, no attendance inflation — heads-at-doors is logged as-is.

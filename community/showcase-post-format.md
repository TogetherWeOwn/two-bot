# TWO member-showcase post format + 3 exemplar drafts

> DRAFT ONLY — copy only, no post, no DM, no bot change. For CPO copy
> approval. Human-posted: a human adapts one exemplar or fills the format,
> gets the member's OK on the final text, and posts. No live-guild action in
> this slice.

| | |
|---|---|
| Intended channel | Landing / media channel (CPO picks per edition; never a DM) |
| Intended use | Member shows their own work: a clip, a build, art, a strat write-up, a funny moment |
| Cadence guard | Max 1 showcase/week; never adjacent to a Sunday Squad announcement day; showcase bows to the ritual |
| Sibling format | `contributor-spotlight-template.md` is staff thanking a member; this format is a member showing their own work (reshared with OK) |

## Rules (privacy + tone, non-negotiable)

1. **Member's work, member's OK:** the member submits (or agrees to) the
   feature *and* signs off the final text before anything posts. A "yes to the
   idea" is not a yes to the copy.
2. **No DMs to arrange it:** invite in the open (a pinned prompt in the media
   channel) or reshare from an already-public post with permission. The bot
   never DMs; neither does this format's workflow.
3. **Show the thing, not the person:** what they made, how they made it (one
   line, so others can try), where to see/play it. No ranks, no leaderboards,
   no "best of".
4. **Per `docs/PRIVACY.md`:** we store IDs and timestamps, never message
   content — so write from what the member gave you with permission, never by
   quoting DMs or pulling logs.
5. **One soft invite:** every edition ends with the same low-bar line (see
   template). No sign-up, no form, no thread required.

## Paste-ready format

```text
🎨 **Member showcase: {title} — by {display_name}**

{what_it_is in one sentence — e.g. "A 40-second clutch comeback on Slime Climb, final stretch."}

How they did it: {one line a newcomer could copy — e.g. "Held the outside lane on the rollers and dive-jumped the last gap."}

See it: {link or "in #media-channel"}

Got something? Drop it in #media-channel — anything you made, found, or pulled off. That's the whole bar. 👏

— shared with {display_name}'s OK
```
